# Phase 1：連続再生

## 仕組み

```
スライドのタブ（content script）                     サイドパネル
 ├ 開いた時点で pptx を裏で取得 → chrome.storage.local に保存
 │   （保存結果があれば使う。30 分より古ければ、パネルを開いたときに取り直す）
 ├ 表示中のスライドを 0.4 秒ごとに確認 ── slideChanged ──→ 手動で切り替えたら、そのスライドから読み直す
 ├ slideText：保存結果があれば pptx の本文とノート、        ← 再生：文ごとに chrome.tts で読む
 │            無ければ画面の文字（source: 'dom'）              → 読み終えたら next → 繰り返す
 └ next / prev：→ / ← キーを送り、切り替わるまで待つ
```

- 画面の文字から読む場合：スライドショーでは `g[id^="a11y-"]` の `aria-label` を、編集画面では `g#editor-<ID>` 内の段落を、図形の位置の順に読む。ノートは編集画面でのみ取れる。
- 保存結果に無いスライド（取得後に追加されたスライド）を開いたら、1 回だけ自動で取り直す。
- 読み上げ用の整形（`src/lib/speech-text.js`）：行頭の箇条書き記号と絵文字を消し、URL は「URL」と読む。文末・改行で区切り、200 文字を超える文は読点で分ける。
- 設定（読む内容、自動で次へ、スライド間の間、音声、速度）は `chrome.storage.local` に保存する。既定の音声は Kyoko。
- 一時停止に対応していない音声（Google 日本語など）では、一時停止ボタンが停止として動く。

## 確認項目

組み込みブラウザでは拡張を読み込めないため、画面の文字の取り出しだけを公開サンプルで確認済み（スライドショー・編集画面とも、本文とノートを取れた）。以下は自分の Chrome で確認する。

- [ ] 初めて開いた資料で、取得中は画面の文字で読み、取得が終わると「取得済み」に変わる
- [ ] 2 回目に開いたときは、すぐに「取得済み」になる
- [ ] 再生すると、本文→ノートの順に読み、次のスライドへ進み、最後のスライドで止まる
- [ ] 一時停止・再開・停止・前へ・次へ
- [ ] 再生中にスライドを手でクリックして切り替えると、そのスライドから読み直す
- [ ] 読む内容（本文だけ／ノートだけ）、速度、音声の変更
- [ ] `/present` の画面での連続再生
