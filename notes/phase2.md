# Phase 2：ショートカットと読み方の辞書

## キーボードショートカット

| 操作 | 既定のキー（Mac では Alt = Option） |
|---|---|
| 再生／一時停止 | Alt+Shift+P |
| 次のスライドへ | Alt+Shift+→ |
| 前のスライドへ | Alt+Shift+← |
| 停止 | Alt+Shift+S |

- `chrome.commands` で定義した。キーは `chrome://extensions/shortcuts` で変えられる（サイドパネルの「ショートカットを変更する」から開く）。
- 再生の制御はサイドパネルにあるので、バックグラウンドが受け取ったショートカットを、ウィンドウごとのポート（`sidepanel:<windowId>`）でパネルへ送る。
- パネルが閉じていれば `chrome.sidePanel.open` で開き、開いたパネルが接続してきたときに、そのショートカットを実行する（10 秒以内）。`sidePanel.open` はショートカット操作の中で同期的に呼ぶ必要があるため、パネルの有無は接続中のポートで判断する。
- バックグラウンド（Service Worker）が休止するとポートが切れるので、パネル側が 0.5 秒後につなぎ直す。
- 全画面のスライドショーではサイドパネルが見えないが、ショートカットで操作できる。

## 読み方の辞書

- サイドパネルの「読み方の辞書」で、1 行ずつ「スライドの文字」と「読み方」を入力する。「＋ 語句を追加」で行を増やし、「✕」で消す。読み方の欄で Enter を押すと次の行へ移る。
- 「▶」でその行の読み方を試し聞きできる（再生中は鳴らさない）。
- 読み上げる直前にだけ置き換え、画面の表示は元の文字のまま。
- 長い表記を優先し、1 回の走査で置き換える（置き換え後の読みが別の表記に当たっても、二重には置き換えない）。
- 同じ文字を 2 回登録したときは上の行を使い、下の行をオレンジ色にして説明を出す。
- 大文字と小文字は区別する。
- 保存形式は `settings.dictionaryRows`（`[{ from, to }]`）。最初の版の「表記=読み」の文字列（`settings.dictionary`）で保存されていれば、読み込むときに自動で移す。
